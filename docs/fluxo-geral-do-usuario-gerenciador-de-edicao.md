# Gerenciador de Edição - Fluxo Media 8

## 1. Cadastro e pacotes
- Usuário cria conta na plataforma.
- Usuário compra um pacote com quantidade X de edições.
- Cada edição consumida reduz o saldo disponível desse pacote.

---

## 2. Perfis de Edição
**Perfil de edição** = briefing com estilo desejado para vídeos.

Contém:
- Referências visuais e sonoras.
- Identidade visual.
- Estilo de edição.
- Sentimento desejado.
- Informações gerais padrão.

Usuário pode:
- Selecionar um perfil existente.
- Criar novo perfil e preencher briefing.

---

## 3. Criação de projeto de edição
Ação principal: **Criar novo projeto**.

Campos obrigatórios:
1. Selecionar pacote de consumo (exemplo: Reels 10/10 passa para 9/10 após uso).
2. Selecionar perfil de edição.
3. Título do vídeo.
4. Headline para capa.
5. Informações adicionais específicas do vídeo.
6. Link para materiais de edição (Google Drive com fotos, vídeos, áudios e arquivos necessários).

Após preencher:
- Usuário confirma em **Criar Projeto**.
- Sistema registra solicitação e desconta 1 edição do pacote escolhido.

---

## Resumo do fluxo
Cadastro → Compra de pacote → Criar perfil de edição → Criar projeto → Selecionar pacote → Selecionar perfil → Preencher campos → Confirmar → Saldo reduzido
