# Criação de Projeto de Edição (Media 8)

## Objetivo
Registrar uma solicitação de edição de vídeo vinculada a um pacote e a um perfil de edição.

---

## Ação principal
Usuário acessa área de projetos e clica em **Criar projeto**.

---

## Passo a passo detalhado

### 1. Seleção do pacote
- Sistema lista pacotes ativos com saldo disponível.
- Usuário seleciona qual pacote será consumido para este projeto.
- Ao concluir a criação, o sistema desconta 1 edição do pacote escolhido.

### 2. Escolha do perfil de edição
- Sistema exibe perfis já cadastrados.
- Usuário escolhe um perfil existente.
- Caso não tenha perfil, o usuário pode criar um novo preenchendo o briefing no momento da criação do projeto.

### 3. Preenchimento dos dados do projeto
O usuário informa:

1. **Título do Projeto**
   - Nome para identificação interna do job.

2. **Headline para capa**
   - Texto principal que aparecerá na capa/thumbnail do vídeo editado.

3. **Informações adicionais específicas**
   - Campo livre para observações extras do projeto.
   - Exemplo: inserir imagem específica, sincronizar com trecho do vídeo X, destacar fala Y.

4. **Link dos materiais**
   - URL contendo todos os arquivos necessários para a edição.
   - O usuário coloca tudo em uma pasta no Google Drive e cola o link.

### 4. Finalização
- Usuário clica em **Criar Projeto**.
- Projeto é salvo no banco.
- 1 crédito de edição é debitado do pacote selecionado.
- Projeto entra para fila/gestão interna de edição.

---

## Resultado esperado
Projeto cadastrado com todas as informações necessárias para o editor iniciar o trabalho, vinculado a um pacote e a um perfil de edição.
